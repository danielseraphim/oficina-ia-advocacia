## O que está aqui

- **[Os slides](slides/oficina.html)** — baixe o repositório e abra o
  `oficina.html` no navegador (setas navegam, `F` põe em tela cheia). As
  fontes estão embutidas: funciona offline.
- **As três animações**, que abrem sozinhas no navegador: o
  [sorteio de palavras](slides/animacao-llm.html), o
  [escritório de ferramentas](slides/animacao-harness.html) e o
  [oráculo de Delfos atendendo por aplicativo](slides/animacao-oraculo.html).
- **[O roteiro](roteiro/)** que eu escrevi para a noite, inteiro — inclusive
  os planos B e o que eu faria se a internet caísse.
- **[As normas e os julgados citados](referencias.md)**, com o link de cada
  um, para você conferir o que eu falei.
- **[Os documentos fictícios](materiais/)** que apareceram na tela.
- **[Como a pasta funciona](LEIAME.md)** — para quem quiser gerar o deck,
  mexer no tema ou reaproveitar isto numa aula sua.

**Aviso que vale por todos:** o contrato, o distrato e uma das duas ementas da
abertura são **fabricados por mim**, de propósito, para a oficina. A ementa
falsa foi escrita para parecer verdadeira — tese correta, formatação correta,
julgado inexistente. Ela existe para mostrar como é fácil acreditar.

Se você chegou aqui por uma busca: **não cite nada deste repositório como
precedente.**

Os gabaritos das armadilhas plantadas no contrato e no distrato ficaram de
fora. Elas se acham lendo, que é o exercício.
